আমি এমন একটি general lottery/combination optimization software চাই, যেটা শুধু এক game-এর জন্য হবে না।

আমি প্রতিবার game-এর input নিজে দেব:
- Number range (0 থেকে 40-এর মধ্যে যেকোনো range)
- Ticket size
- Result size
- Exact match target এক বা একাধিক

উদাহরণ:
Exact 5 match >= 1
Exact 4 match >= 10
Exact 3 match >= 25

সবচেয়ে গুরুত্বপূর্ণ নিয়ম:
যে game দেওয়া হবে, ওই game-এর যত possible result আছে, সব result-এর বিরুদ্ধে guarantee check করতে হবে।
Random/sample checking দিয়ে 100% guarantee বলা যাবে না।

যদি Exact 4 >= 10 দিই, তাহলে সবচেয়ে খারাপ possible result এলেও exact 4 match অন্তত 10 বার হতে হবে।

Priority:
1) 100% worst-case guarantee
2) যত কম ticket দিয়ে সম্ভব target পূরণ করা
3) সব result-এর match count যতটা সম্ভব balanced রাখা

Global minimum solver দিয়ে prove হলে শুধু তখন PROVED OPTIMAL দেখাবে।
Proof না থাকলে BEST FOUND দেখাবে।
Proof ছাড়া minimum/optimal লেখা যাবে না।

Verification report:
- Total tickets
- Total possible results checked
- প্রতিটি exact match level-এর min/max/average
- Worst-case result
- Best-case result
- Target PASS/FAIL
- Solver status: PROVED OPTIMAL / BEST FOUND / INFEASIBLE

Recommended tools:
- Python: main code
- itertools.combinations: combinations generate
- bit-mask + int.bit_count(): দ্রুত exact-match count
- NumPy: batch speed-up
- OR-Tools CP-SAT: main exact optimizer
- Gurobi: optional advanced exact solver
- SCIP: optional exact solver alternative
- Streamlit: UI
- CSV/XLSX: export

Large problem-এর জন্য iterative constraint generation ব্যবহার করবেন:
solver candidate বানাবে -> verifier সব result check করবে -> failed result constraint হিসেবে add করবে -> re-optimize করবে -> সব result pass না করা পর্যন্ত repeat করবে।

Final verification অবশ্যই exact হবে।
